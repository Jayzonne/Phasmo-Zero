# Phasmo Zero

**The no-evidence journal for Phasmophobia.** Answer Yes or No to what the ghost does, and every impossible ghost gets crossed out automatically — like the in-game journal, but built for games with 0 evidence (or very little).

**Live page:** https://jayzonne.github.io/Phasmo-Zero/

## Features

- **All 30 ghosts** in the in-game journal order, up to the Deildegast (game version 0.19, November 2026).
- **About 80 behaviour signs** in three groups: *Outside hunts*, *During hunts* and *Over time*, with one search bar for all of them.
- **Simple tests** (salt, incense, photo, candle and crucifix, sensors, summoning circle…) that only show tests still useful for the remaining ghosts.
- **Yes / No answers** everywhere. A "No" only rules ghosts out when the absence is real proof.
- **Game settings**: starting sanity, sanity pills, sanity drain, evidence given (0–3), fuse box, solo or group, available equipment. Impossible tests are greyed out with the reason, or hidden with the *Hide greyed-out choices* option.
- **Classic evidence** (EMF 5, Spirit Box, UV, Orbs, Writing, Freezing, D.O.T.S.) appears when your game gives 1 to 3 pieces of evidence.
- **Conflicting signs** cancel each other out (normal / slow / fast speed, hunted above 50% / no hunt before 35%…).
- **The best test for each remaining ghost**, with common mix-ups.
- **Name finder**: type a ghost name in English or French, or its ID, to get both names.
- **12 languages**: English, Français, Deutsch, Español, Italiano, Português, Polski, Română, Русский, Türkçe, 中文, 한국어. The language picker (globe button) is always visible at the top right of the screen.

Your answers and settings are saved in your own browser only.

## How to use

1. Pick your language with the globe button at the top right.
2. Set your game settings in the red panel.
3. Answer Yes or No to what you observe. Click the same button again to clear an answer.
4. Run the simple tests to narrow it down, then check the last ghost with its test before locking it in.

## How it was checked

- Ghost behaviour was researched ghost by ghost against the patch notes up to v0.19.1 and recent community guides (November 2026).
- The elimination logic was tested by simulating 100,000+ games: a random ghost, random settings, and players answering honestly. The real ghost was never wrongly crossed out.

## Translations

The non-English and non-French translations were written without native-speaker review. Corrections are welcome: open an issue or a pull request.

## Hosting

The whole tool is a single `index.html` file with no dependencies besides Google Fonts, served with GitHub Pages from the `main` branch.
