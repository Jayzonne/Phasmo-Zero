# Phasmo Zero

**The no-evidence journal for Phasmophobia.** Tick what the ghost does, cross out what it doesn't, and impossible ghosts get crossed out automatically — just like the in-game journal, but built for games with 0 evidence (or very little).

**Live page:** https://Jayzonne.github.io/Phasmo-Zero/

## Features

- **All 30 ghosts** in the in-game journal order, Deildegast included (November 2026).
- **Behaviour signs** grouped into *Outside hunts*, *During hunts* and *Over time*, with a single search bar.
- **Simple tests** (salt, incense, photo, candle, crucifix, sensors…) answered Yes / No; tests that no longer help are greyed out.
- **Game settings**: starting sanity, sanity pills, sanity drain, evidence given (0–3), fuse box, solo or group, available equipment. Impossible tests are greyed out with the reason.
- **Classic evidence** (EMF 5, Spirit Box, UV, Orbs, Writing, Freezing, D.O.T.S.) appears when your game gives 1 to 3 pieces of evidence.
- **Conflicting signs** cancel each other out (e.g. normal / slow / fast speed).
- **Tests to tell the remaining ghosts apart**, with common mix-ups.
- **Name finder**: type a ghost name in English or French (or its ID) to get both names.
- **5 languages**: Français, English, Deutsch, Italiano, Română.

Your answers and settings are saved in your own browser only.

## How to use

1. Set your game settings at the top (red panel).
2. Tick or cross out what you observe. One click = it does it, two clicks = it doesn't, three clicks = clear.
3. Use the simple tests to narrow it down, then check the remaining ghost with its test before locking it in.

## Hosting

The whole tool is a single `index.html` file with no dependencies besides Google Fonts. It is served with GitHub Pages from the `main` branch.
